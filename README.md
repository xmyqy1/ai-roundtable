# AI 圆桌（浏览器插件版）

让你已登录的多个 AI 网页（Dola、豆包、ChatGPT、Claude、Gemini、DeepSeek、Kimi、通义千问、Grok、Perplexity 等 20 个）围坐一桌讨论你的问题，最后由裁判 AI 给出决策报告。不需要 API Key。

## 安装（Chrome 或 Edge）
1. 解压到一个固定的文件夹（以后别删）。
2. 地址栏打开 chrome://extensions （Edge 是 edge://extensions）。
3. 打开右上角「开发者模式」，点「加载已解压的扩展程序」，选这个文件夹。
4. 点工具栏的拼图图标，把「AI 圆桌」固定出来，点它就打开圆桌页面。

## 使用
1. 「网站设置」里点各网站的「打开」，在这个浏览器里登录一次。
2. 「新的圆桌讨论」：写问题，选参与的 AI（来源可以是任意网站，或“手动复制粘贴”）、角色、轮数、裁判。
3. 开始后插件会在屏幕右半边开一个 AI 窗口，依次在各网页里提问、读取回答。讨论时别最小化这个窗口。
4. 某个网站自动操作失败时，这一步会变成复制粘贴：复制提示词发给 AI，把回答贴回来，讨论继续。

## 网站改版了怎么办
「网站设置 → 高级」里可以改每个网站的输入框、发送按钮、回答的 CSS 选择器，不用改代码。

## 隐私与风险
所有记录只存在你自己的浏览器里。自动操作网页可能不符合部分网站的使用条款，请适度使用。
